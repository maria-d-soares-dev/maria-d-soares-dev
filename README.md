## 🦇 Featured projects

### 𖤐 PDA Sentinel

A rule-based Python application that validates operational spreadsheets before the data is used in formulas and reports.

**Features:** required-field validation, possible duplicate detection, inconsistent time checks, atypical duration alerts, column mapping, indicators, and interactive results.

`Python` `pandas` `Streamlit` `openpyxl` `Plotly` `pytest`

### 🐈‍⬛ Miau Atende

A text classification project built with synthetic delivery messages, focusing on model evaluation rather than only training.

**Topics:** text representation, train-test separation, confusion matrix, precision, recall, F1-score, error analysis, and limitations of synthetic data.

`Python` `pandas` `scikit-learn` `NLP` `Machine Learning`

### 🕸️ Refund and Cancellation Knowledge Retrieval

An educational proof of concept for retrieving simulated refund and cancellation guidance from a CSV knowledge base.

The first version uses TF-IDF, cosine similarity, source display, and a safe fallback when the available evidence is insufficient.

`Python` `pandas` `scikit-learn` `Streamlit` `pytest`

> The knowledge base is simulated and does not represent official company policies.
